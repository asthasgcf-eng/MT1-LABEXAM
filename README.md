# Employee Task Management System

## Project Description

This project is developed using Node.js and Express.js.

It allows users to manage employee tasks.

## Technologies Used

- Node.js
- Express.js
- JavaScript
- HTTP Module
- FS Module

## Part A - HTTP Server

Port: 3000

Features:
- Home Page
- Display All Tasks
- Add Task
- Update Task
- Delete Task
- Read HTML File Using FS Module

## Part B - REST API

Port: 4000

CRUD Operations:

- GET /tasks
- GET /tasks/:id
- POST /tasks
- PUT /tasks/:id
- DELETE /tasks/:id

## How to Run

Install dependencies:

npm install

Run HTTP Server:

node httpServer.js

Run Express Server:

node expressApp.js
